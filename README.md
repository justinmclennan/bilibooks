# LinguStory

A language-learning story generator that creates structured bilingual stories and audio using OpenAI GPT-4o and Google Cloud Text-to-Speech.

## Features
- **OpenAI Story Generation:** Multi-chapter planning and pedagogical validation.
- **Google Cloud TTS:** Dual-voice audio synthesis.
- **Local Library:** Save and retrieve your generated stories.

## Setup
1. Install dependencies: `npm install`
2. Create `.env` from `.env.example` and add your API keys.
3. Start the app: `npm run dev:all`

## Requirements
- Node.js
- OpenAI API Key
- Google Cloud Credentials (for TTS)
